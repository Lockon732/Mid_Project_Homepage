Market Screener Bot — Indodax

Bot yang memindai pasar kripto Indodax secara real-time, fokus pada pair berlikuiditas rendah untuk mendeteksi anomali volume dan pergerakan agresif (Pump, Dump, atau akumulasi paus).

Fitur utama:

  • Scan otomatis seluruh pair IDR dengan Liquidity Filter
  • Klasifikasi ukuran transaksi (Shrimp hingga Leviathan)
  • Global Price Gap Analysis — deteksi arbitrase dan maintenance trap
  • Log real-time ke SQLite (WAL Mode) untuk dataset AI

Android · Java · SQLite

Habit Tracker

Aplikasi Android dari tugas mata kuliah Rekayasa Perangkat Lunak (RPL). Dirancang untuk memantau rutinitas harian dengan kalender bulanan yang warnanya beradaptasi sesuai persentase konsistensi pengguna.

Fitur utama:

  1. Manajemen rutinitas CRUD lengkap dengan kustomisasi ikon/emoji.
  2. Kalender bulanan — indikator warna berbasis progres harian.
  3. Streak counter spesifik per rutinitas.
  4. Ringkasan statistik harian (target, pencapaian, persentase).

Python · Computer Vision · Desktop Automation

Autostepper — Vision-Based Game Bot

Bot automasi berbasis computer vision untuk mengoperasikan game browser secara otonom menggunakan PyAutoGUI. Klik disimulasikan dengan gerakan kursor menyerupai manusia menggunakan easing function.

Fitur utama:

  1. Template matching dengan confidence threshold 0.80–0.90.
  2. Humanized click dengan randomisasi posisi dan durasi.
  3. Dual-mode: Stepping (eksplorasi) dan Arena Grind (farming otomatis).
  4. Deteksi CAPTCHA + notifikasi Discord via Webhook.
